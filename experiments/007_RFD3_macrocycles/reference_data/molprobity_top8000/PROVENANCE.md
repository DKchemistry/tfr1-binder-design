# MolProbity Top8000 Ramachandran reference data

These six `rama8000-*.data` files are an unchanged copy of the official
Richardson Lab `rotarama_data` repository at commit:

`76aae74c6e1f834775f8df4700c79602c6a8b9ec`

Source: <https://github.com/rlabduke/rotarama_data>

Downloaded: 2026-10-03

The upstream `README.md` provides the requested citations. The upstream
`LICENSE` grants use under CC BY 4.0. The files are stored locally so this
experiment remains reproducible without a network request or an unpinned
external dataset.
